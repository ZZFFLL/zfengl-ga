# GA Browser B+A Iframe Overlay Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reduce `browser_*` tool-chain breakage on same-origin iframe enterprise forms by closing the `browser_state -> browser_find -> browser_action -> browser_recipe` loop for iframe content, dynamic overlay content, and failure recovery.

**Architecture:** Keep GA on the existing real-user Chrome plus TMWebDriver path, and keep `web_execute_js` as a peer low-level escape hatch. Strengthen only the `ga_browser_use` structured layer: `indexer.py` must expose enough iframe and overlay state to make structured actions viable, `finder.py` and `recipes.py` must preserve that context across steps, and `actions.py`/`results.py` must stop agents from repeatedly retrying dead-end paths.

**Tech Stack:** Python 3, pytest, embedded JavaScript generated by `ga_browser_use/indexer.py` and executed via existing browser unit tests, GA tool schemas in `assets/tools_schema.json` and `assets/tools_schema_cn.json`, GA SOP doc in `memory/browser-use_sop.md`.

- [ ] **Step 3: Implement iframe reservation and truncation metadata**

In `ga_browser_use/indexer.py`, adjust the generated JavaScript around `collectDocumentElements`, `collectFrameElements`, `elements`, and the final result so it follows this shape:

```javascript
  const budget = {
    total: maxElements,
    mainReserved: Math.max(1, Math.floor(maxElements * 0.6)),
    frameReserved: Math.max(1, maxElements - Math.max(1, Math.floor(maxElements * 0.6))),
    mainUsed: 0,
    frameUsed: 0,
    omitted: 0,
    iframeOmitted: 0,
  };

  const addElement = (element, framePath, frameWindow, sourceKind) => {
    const targetBucket = sourceKind === "frame" ? "frameUsed" : "mainUsed";
    const targetReserve = sourceKind === "frame" ? budget.frameReserved : budget.mainReserved;
    if (!element || seenElements.has(element)) return;
    if (elements.length >= budget.total) {
      budget.omitted += 1;
      if (sourceKind === "frame") budget.iframeOmitted += 1;
      return;
    }
    if (budget[targetBucket] >= targetReserve && (budget.mainUsed + budget.frameUsed) < budget.total) {
      budget.omitted += 1;
      if (sourceKind === "frame") budget.iframeOmitted += 1;
      return;
    }
    seenElements.add(element);
    budget[targetBucket] += 1;
    elements.push({ element, framePath, frameWindow, sourceKind });
  };
```

```javascript
    truncated: budget.omitted > 0,
    truncation: {

      iframe_omitted_count: budget.iframeOmitted,
      total_limit: budget.total,
      main_reserved: budget.mainReserved,
      frame_reserved: budget.frameReserved,
    },
```
