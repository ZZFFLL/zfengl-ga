<objective>
Create the in-repo `tools/searchserver/` provider layer that lets GA discover and call concrete search services behind one future model-visible tool. Implement Tavily as the first provider, including `mykey.py`-style config loading, multi-key rotation, structured result/error payloads, provider discovery, and deterministic tests.
</objective>

<must_haves>
<truth id="D-01">Search service code lives under `tools/searchserver/`.</truth>
<truth id="D-03">Provider count must not leak into the model-visible tool list.</truth>
<truth id="D-04">Future providers only implement concrete service API calls behind the provider layer.</truth>
<truth id="D-07">Tavily is the default v1 provider.</truth>
<truth id="D-08">Search provider keys and full endpoint URLs are maintained in `mykey.py`.</truth>
<truth id="D-09">Different search services use different variable names for keys and URLs.</truth>
<truth id="D-10">Provider keys support rotation when one key cannot be used.</truth>
<truth id="D-11">Provider failures allow fallback to the next available service.</truth>
<truth id="D-12">If all providers fail, return that search cannot be performed.</truth>
<truth id="D-13">All-failed responses include every provider's error reason.</truth>
<truth id="D-15">Tests cover discovery, invocation, key fallback, provider fallback, and all-failed reporting.</truth>
</must_haves>

## Decision Coverage

- D-01: Search service code lives under `tools/searchserver/`.
- D-03: Provider count must not leak into the model-visible tool list.
- D-04: Future search providers should only need to implement the concrete service API call to become discoverable.
- D-07: Tavily is the default v1 provider.
- D-08: Search provider keys and full endpoint URLs are maintained in `mykey.py`.
- D-09: Different search services use different variable names in `mykey.py` for keys and full URL endpoints.
- D-10: Provider keys support rotation when one key cannot be used.
- D-11: Provider failures allow fallback to the next available service.
- D-12: If all providers fail, return that search cannot be performed.
- D-13: All-failed responses include every provider's error reason.
- D-15: Tests cover discovery, invocation, key fallback, provider fallback, and all-failed reporting.
