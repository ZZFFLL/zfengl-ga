# Testing Patterns

## Scope

This document maps the Python and HeroUI frontend test stack, important coverage areas, fake/mock conventions, temporary-path usage, frontend contract tests, and focused validation commands. Commands listed here are recommended focused checks; no project-wide tests, linters, formatters, or builds were run during this mapping.

## Test Stack

### Python

- Tests live under `tests/` and are executable by pytest-style discovery. Evidence: `tests/__pycache__/` contains pytest-generated bytecode such as `test_agent_loop_events.cpython-313-pytest-9.0.2.pyc`.
- The source files mix plain pytest functions and `unittest.TestCase` classes:
  - Plain pytest style: `tests/test_agent_loop_events.py`, `tests/test_agent_streaming.py`, `tests/test_heroui_agent_state.py`, `tests/test_heroui_session_store.py`.
  - `unittest.TestCase` style with `if __name__ == "__main__": unittest.main()`: `tests/test_llmcore_fast_ask.py`, `tests/test_long_run_context.py`, `tests/test_simple_http_server.py`, `tests/test_goal_mode.py`.
- Python tests mostly use standard-library assertions/mocking plus pytest fixtures when needed:
  - `unittest.mock.patch` in `tests/test_llmcore_fast_ask.py`.
  - `tmp_path` in `tests/test_heroui_session_store.py`.
  - `tempfile.TemporaryDirectory()` in `tests/test_goal_mode.py`.
  - Local fake classes in `tests/test_agent_loop_events.py` and `tests/test_heroui_agent_state.py`.
- No `pytest.ini`, `tox.ini`, `noxfile.py`, or pytest config in `pyproject.toml` was detected.

### Frontend

- HeroUI frontend tests live beside source under `frontends/heroui/src/*.test.mjs`.
- Test runner is Node's built-in `node:test`, launched through `tsx` to import TypeScript files directly.
- `frontends/heroui/package.json` defines:
  - `pnpm test` -> `tsx --test src/state.test.mjs src/tool_details.test.mjs src/ui_contract.test.mjs src/ga_bridge_contract.test.mjs src/ga_output_parser.test.mjs src/api_stream.test.mjs src/sop_prompt.test.mjs`
  - `pnpm build` -> `tsc --noEmit && vite build`
- Frontend tests use `node:assert/strict`, `node:test`, and direct file/source inspection for contract tests.

## Python Test Organization

### Core behavior tests

- `tests/test_agent_loop_events.py` covers `agent_loop.py` structured event ordering, tool event payloads, legacy chunk behavior, sanitized model deltas, final text sanitization, file/tool error classification, and default `GenericAgent.structured_events`.
- `tests/test_agent_streaming.py` covers `agent_streaming.py` filtering of `<thinking>`, `<tool_use>`, `<file_content>`, malformed summary closing tags, split protocol tags, EOF handling, and summary extraction fallback.
- `tests/test_llmcore_fast_ask.py` covers `llmcore.fast_ask` payload shape for a native Claude session and verifies plain prompt calls omit tools.
- `tests/test_long_run_context.py` covers `ga.GenericAgentHandler.turn_end_callback` behavior for normal/plan long-run prompts, checkpoint cadence, stall warnings, working-memory windows, and `agentmain.NORMAL_RUNNER_MAX_TURNS`.
- `tests/test_goal_mode.py` covers `reflect/goal_mode.py` wake-count progression and state-file persistence.
- `tests/test_simple_http_server.py` covers `simple_http_server.py` JSON GET, JSON POST, and invalid JSON error responses against a real local HTTP server in a background thread.

### HeroUI bridge Python tests

- `tests/test_heroui_agent_state.py` covers `frontends/heroui/agent_state.py` capture/restore of GenericAgent runtime fields, delayed handler working restore, authoritative empty SQLite state, message-derived fallback state, current-turn exclusion, and working-state merge semantics.
- `tests/test_heroui_session_store.py` covers `frontends/heroui/session_store.py` schema creation, session/message/event/agent-state round trips, cascade delete behavior, state-only deletion, corrupt state fallback, and the invariant that `temp/model_responses` import/restore is absent.
- `frontends/heroui/src/ga_bridge_contract.test.mjs` also runs Python bridge snippets through `execFileSync("python", ["-c", script])` to cover `frontends/heroui/bridge.py` behaviors such as turn replay, persistence, session model switching, restored state, cancellation, terminal events, and stale worker write prevention.

## Frontend Test Organization

### Pure TypeScript behavior tests

- `frontends/heroui/src/state.test.mjs` imports `applyStreamEvent`, `appendFinalAssistantMessage`, `buildTurnRounds`, `createInitialTurnState`, `findLatestHumanInteractionPrompt`, `mergeCompletedTurnIntoHistory`, and `buildThreadItems` from `frontends/heroui/src/state.ts`.
- `frontends/heroui/src/state.test.mjs` covers answer streaming, response retraction, phase localization, tool start/end cards, timeline step updates, artifact creation, ask_user prompt handling, turn error/done transitions, elapsed time propagation, completed-turn merge behavior, and thread/round ordering.
- `frontends/heroui/src/tool_details.test.mjs` covers `frontends/heroui/src/tool_details.ts` formatting for default web_scan/code/browser args, no-argument tools, normal args, and legacy detail parsing.
- `frontends/heroui/src/ga_output_parser.test.mjs` covers `frontends/heroui/src/ga_output_parser.ts` parsing of GenericAgent verbose logs into tool cards while excluding final assistant answers.
- `frontends/heroui/src/sop_prompt.test.mjs` covers `frontends/heroui/src/sop_prompt.ts` prompt expansion, display prompt redaction, empty SOP references, and trailing at-sign trigger removal.

### API/stream tests

- `frontends/heroui/src/api_stream.test.mjs` covers `frontends/heroui/src/api.ts` `subscribeTurn` behavior:
  - EventSource is preferred and closed on `turn.done`.
  - Polling fallback starts only when EventSource fails before data arrives.
  - EventSource remains open on errors after data arrives.
  - Events from previous turns are ignored.
  - Polling avoids duplicate backend terminal events.
  - Legacy outputs are preserved after backend replay.
  - `elapsed_ms` is forwarded.
  - Raw partial text is not streamed after structured events are present.
- Tests monkeypatch `globalThis.EventSource`, `globalThis.fetch`, and `globalThis.window` and restore originals in `finally` blocks. Preserve this pattern for global fakes.

### UI/source contract tests

- `frontends/heroui/src/ui_contract.test.mjs` is a source-level contract test. It reads `App.tsx`, `api.ts`, `state.ts`, component files, `styles.css`, `package.json`, and bridge Python files, then asserts UI strings, HeroUI usage, layout invariants, event names, endpoint names, and forbidden regressions.
- `frontends/heroui/src/ga_bridge_contract.test.mjs` is a source and integration contract test. It reads bridge/frontend files and runs isolated Python scripts in temp directories for behavior that is hard to assert from TypeScript alone.
- These contract tests intentionally assert both presence and absence with `assert.match` and `assert.doesNotMatch`. When changing UI text, API names, or bridge architecture, update these tests only when the contract intentionally changes.

## Fake and Mock Conventions

### Python fakes

- Prefer small local fake classes over external mocking frameworks:
  - `tests/test_agent_loop_events.py` defines `FakeFunction`, `FakeToolCall`, `FakeResponse`, `FakeClient`, `StreamingProtocolClient`, `NoToolProtocolClient`, `FakeParent`, and handler subclasses.
  - `tests/test_heroui_agent_state.py` defines `FakeBackend`, `FakeLlmClient`, `FakeHandler`, and `FakeAgent`.
- Fake LLM clients should implement only the methods used by the subject, typically `chat(messages, tools)` yielding chunks and returning a fake response via generator return value.
- Fake handlers should subclass `BaseHandler` when testing `agent_runner_loop`; implement `do_<tool>` methods that yield detail chunks and return `StepOutcome`.
- Patch only hard external edges. `tests/test_llmcore_fast_ask.py` patches `llmcore.resolve_session` and `llmcore._stream_with_retry` while asserting the payload sent into the fake stream.

### Frontend fakes

- API stream tests replace globals directly and restore them:
  - `globalThis.EventSource = FakeEventSource`
  - `globalThis.fetch = async (...) => ({ ok: true, async json() { ... } })`
  - `globalThis.window = { setTimeout: () => 0 }`
- Bridge contract tests create temporary Python scripts as strings and execute them with `execFileSync("python", ["-c", script], { stdio: "pipe" })`.
- Source contract tests use `readFileSync` against real files instead of rendering the DOM. They are fast structural guardrails, not browser UI tests.

## Temporary Paths and Isolation

- Python tests use pytest `tmp_path` for SQLite database isolation in `tests/test_heroui_session_store.py`.
- Python tests use `tempfile.TemporaryDirectory()` for file-backed goal state in `tests/test_goal_mode.py`.
- Node tests use `mkdtempSync(join(tmpdir(), "ga-heroui-bridge-"))` and cleanup with `rmSync(tempDir, { force: true, recursive: true })` in `frontends/heroui/src/ga_bridge_contract.test.mjs`.
- Tests import modules by file path when they need isolation from package import state:
  - `importlib.util.spec_from_file_location` in `tests/test_heroui_agent_state.py` and `tests/test_heroui_session_store.py`.
  - `new URL("./api.ts", import.meta.url)` and `fileURLToPath` in frontend tests.
- Keep tests offline and deterministic. Existing tests avoid live LLM/API calls by faking sessions, streams, queues, and HTTP clients.

## Assertions and Test Design

- Assert behavior and contracts, not implementation defaults alone. Good examples:
  - `tests/test_agent_loop_events.py` verifies failed/success tool status decisions for multiple tool result shapes.
  - `frontends/heroui/src/state.test.mjs` verifies state transitions and message/timeline ordering.
  - `tests/test_heroui_session_store.py` verifies persisted data round trips through SQLite, not only method calls.
- Use absence assertions for regressions that must stay fixed:
  - `tests/test_heroui_session_store.py` asserts no `model_responses` restore/import path exists in session storage.
  - `frontends/heroui/src/ui_contract.test.mjs` asserts removed UI labels/settings do not reappear.
  - `frontends/heroui/src/ga_bridge_contract.test.mjs` asserts old API routes and stale persistence patterns are absent.
- For streaming behavior, assert event sequences and terminal state explicitly. `tests/test_agent_loop_events.py` checks exact event type order, while `frontends/heroui/src/api_stream.test.mjs` checks closure/fallback behavior.

Run focused commands for the area you touched. Do not default to project-wide checks for small changes.
